# jev-grep

[English](README.md) | **Русский**

[Навык для агента](docs/skill/jev-grep/SKILL.md) помогает выбирать режимы ввода,
строить конвейеры и интерпретировать результаты. Установите его через Skills CLI:

```sh
npx skills add https://github.com/m407/jev-grep/tree/main/docs/skill/jev-grep --skill jev-grep
```

Навык не устанавливает CLI; см. [быстрый старт](#быстрый-старт) ниже.

Семантический поиск **фрагментов логов и кода** с помощью модели Jev через API.
Можно использовать OpenRouter и других провайдеров, предоставляющих модель
через API, если их endpoint поддерживает протокол запросов и ответов System One,
который использует `jev-grep`; одной совместимости с OpenAI chat API недостаточно.
Вместо регулярного выражения задайте критерий на естественном языке.
`jev-grep` возвращает подходящий текст
с источником, диапазоном строк и, в JSONL, байтовыми координатами.

- **Логи:** чтение текста или JSONL, объединение соседних записей в смысловые
  фрагменты и оценка каждого фрагмента целиком.
- **Код:** `ast-grep` выделяет функции, методы или другие AST-узлы; каждый кандидат
  оценивается независимо с сохранением координат.

```text
text logs -------------------------------+
logs --> agrind --> JSONL {text: ...} ----+--> jev-grep --> human / JSONL
code --> ast-grep --> JSONL matches -----+
```

Rust CLI работает локально; модельная оценка выполняется на настроенном API.
Внешние инструменты запускаются явно в shell-конвейерах. Индекс репозитория
не требуется.

## Быстрый старт

Установка из корня репозитория (нужен Rust с поддержкой edition 2024):

```sh
cargo install --path . --locked
jev-grep --help
```

Настройте endpoint, модель и API-ключ выбранного провайдера через
`JEV_GREP_API_URL`, `JEV_GREP_MODEL` и `JEV_GREP_API_KEY` (либо `--api-url` и
`--model`). См. [руководство по настройке](docs/ru/installation.md).
[Руководство по подключению](docs/ru/deployment.md) содержит пример Zen с fnox;
Zen используется по умолчанию, но не является обязательным провайдером.
Если ключ настроен в fnox, запустите из корня репозитория:

```sh
fnox exec -- jev-grep 'Certificate validation failure' application.log
fnox exec -- jev-grep --format json 'Unresolved network failure' build.log
```

Входной текст отправляется выбранному API. Используйте только данные, которые
вам разрешено передавать. Отбор вероятностный: проверяйте критерий и пороги
на собственных примерах.
