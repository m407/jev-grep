# jev-grep

[English](README.md) | **Русский**

Семантический поиск **фрагментов логов и кода** через HTTP API
[Jev в OpenCode Zen](https://opencode.ai/docs/zen/#jev). Вместо регулярного выражения
задайте критерий на естественном языке. `jev-grep` возвращает подходящий текст
с источником, диапазоном строк и, в JSONL, байтовыми координатами.

- **Логи:** чтение текста или JSONL, объединение соседних записей в смысловые
  фрагменты и оценка каждого фрагмента целиком.
- **Код:** `ast-grep` выделяет функции, методы или другие AST-узлы; каждый кандидат
  оценивается независимо с сохранением координат.

```text
text logs -------------------------------+
logs --> agrind --> JSONL {text: ...} ----+--> jev-grep --> human / JSONL
code --> ast-grep --> JSONL matches -----+
```

Rust CLI работает локально; модельная оценка выполняется на настроенном API.
Внешние инструменты запускаются явно в shell-конвейерах. Индекс репозитория
не требуется.

## Быстрый старт

Установка из корня репозитория (нужен Rust с поддержкой edition 2024):

```sh
cargo install --path . --locked
jev-grep --help
```

Настройте ключ Zen через fnox по [руководству по подключению](docs/ru/deployment.md),
затем запустите из корня репозитория:

```sh
fnox exec -- jev-grep 'Certificate validation failure' application.log
fnox exec -- jev-grep --format json 'Unresolved network failure' build.log
```

Входной текст отправляется выбранному API. Используйте только данные, которые
вам разрешено передавать. Отбор вероятностный: проверяйте критерий и пороги
на собственных примерах.
