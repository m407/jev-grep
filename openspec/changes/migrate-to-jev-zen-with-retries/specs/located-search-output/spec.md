# Spec Delta

## MODIFIED Requirements

### Requirement: Сохранение ошибок и границ внешних процессов

Коды завершения SHALL оставаться 0 при выбранном фрагменте, 1 при отсутствии выбранных фрагментов и 2 при ошибке. Окончательная ошибка останавливает поиск; ранее выведенные результаты не отменяются. Для модельной оценки окончательная ошибка определяется политикой `bounded-api-retries`: временная ошибка отдельной попытки сама по себе не завершает CLI. Ошибки входа и невалидные ответы остаются немедленными ошибками. BrokenPipe обрабатывается без диагностики traceback, как в текущем CLI. Существующие ignore/glob/hidden-правила и выбор stdin по аргументам SHALL сохраняться; они применяются к входным файлам, а не к путям внутри ast-grep JSONL. EOF pipe не содержит кода завершения upstream-процесса, поэтому документация SHALL показывать `set -o pipefail` для shell-конвейеров и не обещать обнаружение сбоя ast-grep/agrind по корректно завершившемуся JSONL.

#### Scenario: Ошибка после результата
- **WHEN** после корректно выданного фрагмента модельная оценка окончательно завершается ошибкой или поступает повреждённая запись
- **THEN** предыдущий JSONL остаётся корректным, диагностика идёт в stderr и процесс завершается кодом 2
