# Tasks

Этот самостоятельный план выполняется вместо `migrate-to-jev-zen`. Перед apply подготовить назначения командой `/openspec-prepare-task-agents migrate-to-jev-zen-with-retries`; не использовать агентов старого change. Каждая задача завершается scope-only review через `external-expert` до установки checkbox. `parallel=yes` ниже допускает совместный запуск только 1.1 и 1.2; последующие задачи сериализованы из-за общих файлов.

Во время планирования обнаружены внешние незакоммиченные изменения, частично покрывающие 1.1/1.2 (см. Context в design). Перед apply согласовать остановку пересекающегося старого плана, перечитать фактический diff и сохранить готовое: задачи означают доведение до контракта и проверку, а не повторное создание уже существующих файлов. Все checkbox данного плана остаются пустыми до собственной проверки и review.
