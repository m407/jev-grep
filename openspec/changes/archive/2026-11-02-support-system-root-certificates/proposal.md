# Proposal

## Why

`jev-grep` сейчас использует встроенные корни WebPKI: установленный в ОС корпоративный или частный корневой сертификат сам по себе не делает HTTPS endpoint доверенным для клиента. Нужна автоматическая поддержка таких корней, чтобы обычная системная настройка доверия работала без отдельного экспорта сертификатов для `jev-grep`.

## What Changes

- Добавить системные доверенные корни к существующим встроенным корням по умолчанию на поддерживаемых Linux, macOS и Windows.
- Применять это доверие к HTTPS-запросам одиночной и групповой оценки через общий HTTP-клиент.
- Сохранить проверку цепочки, имени узла и срока действия сертификата, а также немедленную ошибку при отказе TLS без повторов.
- Проверить поведение локальным HTTPS-сервером; описать системное доверие и процедуру установки тестового CA в изолированной ОС в обеих языковых версиях руководства развёртывания. По согласованному пересмотру приёмки проверка реальных хранилищ Linux/macOS/Windows перенесена в последующую работу из-за отсутствия одноразовых окружений; она не считается выполненной. Локальные TLS-тесты, общие offline-проверки и минимальный live-smoke Zen остаются обязательными.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `jev-zen-integration`: добавить требование автоматического использования корней ОС при HTTPS-соединениях; существующий транспортный контракт сохраняется.

## Impact

- `Cargo.toml` и `Cargo.lock`: включение штатной возможности существующей зависимости `reqwest`; в текущей конфигурации `rustls-tls` системные корни не загружаются, настройки CLI это не исправляют.
- `src/api.rs`: общий `Api::new` уже обслуживает оба вида оценки; отдельный загрузчик сертификатов не требуется.
- `tests/test_cli.py`: расширение существующей локальной TLS-проверки и изоляция окружения сертификатов.
- `docs/deployment.md`, `docs/ru/deployment.md`: модель доверия и воспроизводимая платформенная проверка.
- Сборки сохраняют Rustls и текущие платформы выпуска; добавляются транзитивные зависимости чтения системных сертификатов. Новых флагов CLI и `JEV_GREP_*` настроек не требуется.
